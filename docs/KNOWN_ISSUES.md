# Known limitations

- Bootstrap is design/content/workflow, not a playable Godot build; engine version/runtime tests remain EMP-001 work.
- Generated benchmark sheets contain labels/decoration and possibly inconsistent frames. They are references, not complete interchangeable clothing or animation assets.
- No schedule/daemon/mobile notification channel is enabled by this repository.
- Client model availability, subagents and rendering capability must be checked locally; this repo does not hard-code an unverified model name.
- Public repo publication is owner-authorized; no code/art license is chosen. Do not assume public means freely reusable.
- Four-hour year and long-term aging goals are not a final calendar. Initial demo uses a short explicit service scenario.
- Approval of character direction does not prove age/profession recognition. Runtime checks still needed.
